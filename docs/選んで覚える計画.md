# 選んで覚える — 計画書（2026-09-28）

## なぜ変えるか
用意された30文のパックを順番にやる形は、長続きしなかった。
自分が「これを言えるようになりたい」と思ったものだけを、レッスン直後の熱いうちに覚える形に変える。

## 新しい流れ
1. GABA のレッスンが終わったら、iPhone でレッスン記録を開き、Phrases（と Words）の欄をまるごとコピーする。
2. フレーズデッキのホーム一番上「今週のフレーズ」→「＋ レッスンのフレーズを選ぶ」を押して貼る。
3. 1行ずつチェック欄つきで並ぶ。覚えたいものだけにチェックを入れて「選んだ N 文をやる」。
   - チェックしたものにだけ AI が日本語訳・場面・アドバイスを付ける（英語は一字一句そのまま）。数円。
   - すでに登録ずみのフレーズは「登録ずみ」と出る。チェックすると、そのカードを今週のフレーズに移す（AI は呼ばない）。
4. ホーム一番上の「今週のフレーズ」を押すと、選んだものだけを集中してやる。
   - 卒業のしかたは今までと同じ: 3日続けて「言えた」で卒業。言えなければ3枚後にもう一度出る。
   - 今日の分が終わったら「おかわり」でもう一周できる（連続日数は増えない）。
5. 翌週また選ぶと、その週のぶんが加わる。前の週で卒業していないものは一緒に続く。
6. 卒業したものは「卒業した文の復習」に貯まり、いつでも全部まとめて回せる（骨組みパックの卒業ぶんも一緒）。

## ホームの並び
- 今週のフレーズ（レッスンの日付ごとに「9/27 のレッスン 5文・卒業 2」と並ぶ）
  - 「次のレッスンで使う3文」もここに移す（選んだものの中から、苦手な順に3文）
- 卒業した文の復習
- ふだんの復習（今までどおり）

## 骨組みパックはどうなるか
ホームから外す。データと卒業の記録は消さない。卒業ずみの文は復習に出続ける。

## 選んだものの扱い
- ふだんの復習（SRS）には出さない。二重に出題しないため。
- 一覧には今までどおり出る。

## ついでに直すこと
- バックアップに、徹底モード（選んだもの・骨組み）の進捗が入っていなかった。入れる。

## 分からないこと
- GABA のレッスン記録を iPhone でコピーできるか。できなければ写真から読む方法を足す。
