# フレーズデッキ

自分の実話フレーズで覚える英語単語帳。**登録も学習も iPhone だけ**で完結する PWA。
フレーズ・進捗・APIキーは端末内 (localStorage) のみに保存され、どこにも公開されません。
万一に備えて、フレーズと進捗を **iCloud Drive 等にバックアップ／復元**できます。

記憶が苦手でも続くよう、3本柱で設計:

1. **エピソードでまとめる** — フレーズを「裁判員の話」「魚市場・仕事」等の自分の体験テーマで束ねる。
2. **間隔反復(SRS)** — Leitner 箱方式。覚えてない物ほど頻繁に、覚えた物は間隔を空けて出題。1日8枚まで新規投入。
3. **シチュエーション起点の能動再生** — まず「場面」を提示 → 英語を口に出す → めくって答え合わせ。

## 構成

```
phrase-deck/
├── index.html / app.js / styles.css   # アプリ本体 (素のPWA・ビルド不要)
├── manifest.webmanifest / sw.js / icon.svg
├── data/phrases.json                  # 空のシード (フレーズは端末内に保存)
├── data/modals.json                   # 助動詞の反射の問題 (95問)
├── data/verbs.json                    # 動詞の 3 つの形 (90 個・6 ステップ)
└── data/replies.json                  # 聞き返しで会話を続ける (20 話 × 4 往復)
```

- フレーズ: 「＋ 新しいフレーズを登録」で追加 → 端末内 localStorage。
- 学習進捗 / 音声設定 / APIキー: すべて端末内 localStorage。
- コード(HTML/JS)だけ公開。フレーズ・進捗・APIキーはリポジトリに含まれません。

## 使い方（iPhone）

GitHub Pages で配信 → iPhone Safari で開く → 共有 →「ホーム画面に追加」でアプリ化（オフライン可）。

- 上部で **自己採点 / 入力 / 発話** の3モードを切替。🔊で読み上げ（端末のTTS=無料、声と速さはホームで調整）。
- 「もう一度 / あやふや / 覚えた」で採点 → 次回の出題間隔が決まる。

> アプリの更新でホーム画面のリンクを消す必要はありません。開くたびに自動で最新コードを取得します。

### 助動詞の反射（2026-10-08〜）
本（助動詞＝頭の中の空想を語る言葉。will=確信 / can=現実的に選べる / would=ありえない妄想 / could=やさしい提案 / should=方向 / might・may=かも）の感覚を、考えずに出るまで反復する。
- ホームの「助動詞の反射」→「20問やる」。場面（日本語）と穴あきの英文を見て、7つのボタンから1つをタップ。反応時間を計り、2秒以内なら ⚡。
- 答えると英文を読み上げ、説明が出る。間違いなら「押した助動詞だとこう聞こえる → 正解の本のイメージ → この文での決め手」の3段。間違えた問題は3問後にもう一度出る。
- 初期は正解でも「次へ」を押して進む（説明をじっくり読める）。ホームの箱で「正解なら自動で進む」(1.5秒・タップで即) に切り替えられる。
- 本の推し以外でも通じるもの（Can I / Could I、might / may など）は黄色で正解扱い。
- チップで助動詞を絞れる（最低2つ）。would と could だけ、のような使い方。
- 「助動詞の地図」= 本の感覚を7枚にまとめた参照ページ。例文は読み上げ可。
- 問題は `data/modals.json`（95問、本の例文ベース）。成績は端末内（バックアップに含む）。ふだんの復習や一覧には混ざらない。

### 動詞の 3 つの形（2026-11-14〜）
よく使う動詞ほど -ed にならない（take → took → taken）。「I ＋ 動詞」を反射で言えるようにする。問題は主語と動詞だけ・例文は答えの面に・書かない。
- カード: 「私　見た」のように主語と動詞だけが英語の語順で出る → 口に出す →「答えを見る」で I saw（読み上げ・カタカナ・see · saw · seen）と、その形で始まる例文 1 つ（I saw him at the station.・タップで読み上げ）→「言えた／言えなかった」。
- 1 つの動詞に 3 枚: 現在「私　見る」= I see ／ 過去「私　見た」= I saw ／ 完了「私　もう　見た」= I've seen（「もう」「ずっと」が付いたら I've ＋ 過去分詞）。
- ホームの「今日の 50 問をやる」= ランダムに 50 枚（苦手ほど出やすい）。途中でやめたら残りから。言えなかった 1 枚は 3 枚あとにもう一度（50 問には数えない）。
- 動詞とステップは 6 段 × 15 個 = 90 個（超基本 1・2 → 基本 1・2 → 応用 1・2）。出るのは「いまここ」の段まで。1 枚を続けて 2 回言えたら覚えた、3 枚とも覚えたらその動詞は覚えた、段の 8 割を覚えたら次の段も混ざりはじめる。
- 段を押すと 15 個の一覧（タップで 3 つ続けて読み上げ）。「このステップだけで 50 問」もできる。
- 問題は `data/verbs.json`（Claude が用意。`q` = 3 枚の問題。カタカナはおおよその読み）。成績は端末内 `phrasedeck.verb.v1`（バックアップに含む）。ふだんの復習や一覧には混ざらない。

### 受けのお約束（2026-11-23〜）
相手の一言には決まった受けがある（GABA Snapshots L4-17 Responding と、レッスンで先生に直された形）。それを反射で言えるようにする。ホームの箱「受けのお約束」に 2 つ入っている。

**お約束の反射**（主役）: 相手の一言（読み上げ）→ すぐ口に出す →「答えを見る」→ 受けの文・その種類・ほかの言い方 →「言えた／言えなかった」。動詞の 3 つの形と同じ手触り。
- お約束は 12 種類: 悪い知らせ（Oh no. What happened?）／病気・つらい話（I'm sorry to hear that.）／良い知らせ（That's great! Congratulations!）／びっくりする話（You're kidding!）／気になる一言（Oh really? What is it?）／〜しない・できない（Really? How come?）／これからの予定（Who are you going with?）／済んだこと（How was it?）／人が出てきた（What is he like?）／場所・物（What is it like?）／ぼやき（I know how you feel.）／誘い（Sounds good!）。
- 毎日ランダムに 20 問（苦手ほど出やすい・同じ種類は続けない）。言えなかった 1 枚は 3 枚あとにもう一度。続けて 2 回言えたら覚えた。
- 「お約束の一覧」= 12 種類の早見（例・受け・ほかの言い方。押すと読み上げ）。
- 答えの面に日本語の解説が 1 枚ずつ付く（なぜその受けか・形の注意。`cards` の `n`）。言えなかった一覧にも出る。
- 答えの面の「ことばの意味」= 答えの文に入っている決まり文句（Are you serious? など）ごとに、訳・単語の意味・直訳・使いどころ。`gloss`（`k` 決まり文句・`m` 訳・`d` 詳しく）から、文に含まれるものを自動で出す。「ほかの言い方」とお約束の一覧も、押すと意味が出る。
- 中身は `data/replies.json` の `rules`（お約束）と `cards`（66 枚。`p` 相手の一言 → `a` 返し・`n` 解説）。成績は `phrasedeck.reply.v1` の `cards`・`cdays`。

**会話で使う**（下の「聞き返しで会話を続ける」）: お約束を 4 往復の会話の中で選んで使う。

### 聞き返しで会話を続ける（2026-11-23〜）
相手の一言に Who / Where / What / How long / How come / What is ~ like で返して、会話を続ける反射をつける（GABA Snapshots L4-17「知らせに反応する・聞き返す」の型）。
- ホームの「聞き返しで会話を続ける」→「今日の 3 話をやる」。1 話 = 4 往復。相手の一言が読み上げられる → 返しをすぐ選ぶ（2 つか 3 つ）。ボタンは質問だけの短い形と日本語。選ぶと受けの一言つきの全文（Really? Who are you going with?）が吹き出しになって読み上げられる。
- 会話が続く返しは 2 つで、選んだ方に応じて相手の答えが変わる。前に選んだ返しには「前に選んだ」と出るので、次は別の道を通れる。
- 番によっては噛み合わない返しが 1 つ混ざる（済んだことを聞く形でこれからのことを聞く・相手が言ったことをもう一度聞く・悪い知らせに That's great）。選ぶと理由が出て、選び直す。
- 2026-11-23 に「難しい・テンポを良く」で直した: 選択肢を伏せるのをやめた・短い形にした・日本語を初めから出す・形の間違いの誤答（How is he like? など。データでは `f: 1`）は出さない。
- 最後に「しめの一言」が付き、会話を通しで聞ける。「別の返しでもう一度」で同じ話を別の道で。
- 「日本語」ボタンで訳を消せる（初期は出す）。吹き出しを押すと読み上げ。
- 出る順: まだやっていない話を上から → 一巡したら古い話から。「話の一覧から選ぶ」でどれでも開ける。
- 中身は `data/replies.json`（Claude が用意。`p` 相手の一言・`o` 返し 3 つ〔`r` があれば続く／`x` は噛み合わない理由〕・`c` しめの一言）。話を足すときは talks に足すだけ。成績は端末内 `phrasedeck.reply.v1`（バックアップに含む）。ふだんの復習や一覧には混ざらない。

### フレーズの登録（自動エンリッチ）
1. ホーム →「設定」に **Anthropic APIキー** を一度だけ入力（端末内のみ）。
2. 「＋ 新しいフレーズを登録」→ `｜` 区切りで単語・フレーズを貼り付け。
3. 「取り込んで自動エンリッチ」→ iPhone から直接 Claude を呼び、翻訳・場面・テーマ・難易度・アドバイス・関連付けを生成。
4. プレビューを確認 →「この内容で保存」で端末に追加。

モデルは `app.js` の `MODEL`（既定 `claude-sonnet-4-6`）。料金は登録時のエンリッチのみ。学習・音声再生は無料。

### バックアップ / 復元（データ消失への保険）
- ホーム →「バックアップ」→「⬆️ バックアップを書き出す」→ 共有シートから **iCloud Drive 等に保存**。
- 復元は「⬇️ バックアップから復元」→ そのファイルを選ぶ（今の内容に上書き）。
- リンクを消した・端末を初期化した・機種変した時は、ここから戻せます。APIキーはバックアップに含まれません。
- フレーズを増やした後などに一度押す習慣を。
